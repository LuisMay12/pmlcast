# PMLcast

Day-ahead hourly electricity price forecasting for Mexican grid nodes (CENACE PML, MDA market).

Given the last 7 days of hourly prices at a node, PMLcast predicts the 24 hourly prices of the next day
so solar + storage operators can decide **when to inject (sell) energy**.

Holberton School — Machine Learning Specialization, Portfolio Project. Author: Luis May.

- Project pitch and schedule: [docs/pitch.md](docs/pitch.md)

Data source: [CENACE](https://www.cenace.gob.mx/) public PML web service.
